# 系统视觉改造实施记录

日期：2026-11-08

依据：[视觉与布局方案](visual-design-review-20261108.md)及用户确认“系统主颜色不变 #072941，其他按照观察到的修改”。

## 视觉规则

- 品牌基色保持 `#072941`；顶栏和导航使用同色系低对比渐变，页面增加克制的环境光底纹。
- 首页卡片使用 74%→54% 不透明度的深蓝渐变，专题地图浮窗使用 82%→70% 渐变、14px 背景模糊；内部图层卡仅铺 3%–5% 浅色，避免多层玻璃叠加变浑浊。普通业务面板使用轻透色层；弹窗约 94%–96% 不透明度保障长文本阅读。透明度只应用在背景，不降低文字或整组件的 opacity。
- 主操作采用蓝色系 `#2674D4`，白色小字号标签对比度约 4.6:1；重点与选中提示采用青色。
- 正文 14px，紧凑内容 13px，辅助信息通常 12px；卡片标题 16px，页面标题 20px，核心指标 24–36px。数字与单位分层、基线对齐。
- 普通控件 36px、圆角 9px，卡片圆角 14px，弹窗圆角 18px；间距集中使用 8／12／16／20px。首页左右外边距相同，卡片纵向间距统一 16px；侧栏一级菜单 50px、图标底座 30px，保留箭头固定列。
- hover 统一为约 180ms 的颜色、背景和边框变化，取消全局变暗滤镜；面板收起统一为 220ms，支持减少动态效果偏好。
- 普通长列表使用细滚动条。地图图例和既定无滚动条区域保留例外；标题、搜索、底部操作与正文滚动分开。

## 代码组织

新增 `src/styles/system.scss` 作为共享视觉入口，按职责拆分至 `src/styles/system/`：

- `tokens`：主色、深浅阅读区、字体、间距、状态与组件库变量。
- `controls`：输入、按钮、标签、Tooltip、表格和弹窗。
- `navigation`：主顶栏、任务／飞行／研判／后台侧栏。
- `tasks`：任务列表、总览、待办、详情和工程设施任务详情。
- `maps`：专题工具、图层详情、统计、浮窗、首页地图控件和短屏大屏排布。
- `workspaces`：非粮与工程设施工作台的浅色表单和流程信息。
- `resources`：资源成果、算法、设施台账、机队、工单、后台与登录。
- `operations`：飞行成果研判、图斑研判、日历、航线及工程设施总览。

`App.vue` 仅增加随页面上下文选择视觉变量的属性；工作台与公共页面使用浅色阅读变量，其余使用平台深色变量。任务侧栏字符图标替换为已有图标库的线性图标。任务总览图表的轴、图例、提示文字与背景同步调整。

地图几何、标准地类颜色、勾选状态、统计面积口径、接口及工作流不由这套样式处理。

## 呼吸感修订依据（2026-11-08）

用户反馈上一版过实、圆角与留白不足。本次按以下原则修订，不再将参考站的实体色块机械铺满全站：

- 用透出的底图、微弱高光和柔和投影区分前后关系，模糊只放在地图外层浮窗及短提示中。微软说明 Acrylic 能建立深度与视觉层级，也提醒避免多层透明材质堆叠及过度 GPU 开销。[Microsoft Acrylic](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic)、[Fluent Material](https://fluent2.microsoft.design/material)
- 用一致间距和分组提供视觉秩序，减弱边框与重复底色；关键数字、标题、正文保持不同层级，避免所有区域都同样醒目。[NN/g Visual Hierarchy](https://www.nngroup.com/articles/visual-hierarchy-ux-definition/)
- 14px／9px／18px 圆角、透明度与渐变数值均为本项目的设计选择，不是上述规范规定的固定数值。
- 工作台维持浅色阅读面，增加轻投影与更柔和的圆角；标准地类颜色、分析结果色、几何与业务逻辑不变。
