# 专题空间分析：完整统计与最小图斑过滤的后端需求

本文是待后端实现的接口需求，不代表接口已上线。

## 1. 要解决的问题

用户可以设置“最小结果图斑面积”。地图返回的结果会过滤小图斑，因此结果图斑的面积之和不一定等于完整的空间运算面积。

需要后端同时提供两套口径：

1. **完整统计**：按原始输入、属性条件和分析范围，执行完整空间运算后的真实面积，不受最小输出图斑面积影响。
2. **输出统计**：地图实际返回的图斑面积、数量，以及被最小面积阈值过滤的面积、数量。

右侧分析统计默认展示完整统计；结果图层数量、图例及导出说明使用输出统计。前端不再根据已过滤 GeoJSON 的面积之和推算完整统计，也不把面积差额一概认定为阈值过滤。

当前前端对部分图层的统计依赖结果图斑求和；范围覆盖又存在多步几何比较。接口完成后前端将改为读取后端完整统计，现阶段不能仅新增字段名称而继续由前端补算。

## 2. 统计与阈值规则

- 属性筛选、行政区范围筛选仍然决定输入范围；“完整”指本次选定范围内的完整结果，不是忽略筛选后的全区数据。
- 同一类别先按集合运算处理，输入图斑相互重叠时不重复累计面积。
- 面积沿用后端空间运算的适用投影/测地面积算法，不能直接将 EPSG:4326 的经纬度坐标面积当平方米。返回 `crsUsed` / 面积计算方法。
- 原有 `minAreaSqm` 继续表示平方米。前端输入和展示为亩，只转换一次；1 平方米＝0.0015 亩。面积字段必须带单位后缀，不能悄悄把现有平方米字段改成亩。
- 建议阈值规则明确为：`areaSqm >= minAreaSqm` 保留，`areaSqm < minAreaSqm` 过滤；0 表示不过滤正面积图斑。
- **阈值作用单位必须明确并返回**：`FEATURE`（整条 MultiPolygon 要素）或 `POLYGON_PART`（拆分后的单连通面，扣除其洞面积）。请后端沿用并说明现有行为；如果要变更单位，需同步确认前端并提升算法/缓存版本，不能无提示地改变现有结果。
- 完整统计必须在阈值过滤前计算。阈值只作用于最终输出，不能在中间运算先删除碎片，再用残缺中间结果继续计算后续分类。
- 正常空几何与零面积要素不计入有效图斑；无效几何修复、无法修复、输出超限等情况需独立说明，不能记作“被阈值过滤”。

## 3. 各分析应返回的完整统计

### 高标田与永农对比

A＝高标田，B＝永农。输入先与本次行政区联合范围精确相交（如有选择），再计算：

- 高标田面积 `areaA`、永农面积 `areaB`；
- 高标田中非永农 `A_ONLY`＝A\B；
- 永农中非高标田 `B_ONLY`＝B\A；
- 两者同时满足 `OVERLAP`＝A∩B；
- 差异面积＝完整 A_ONLY＋完整 B_ONLY；
- 差异率＝完整差异面积÷完整高标田面积。返回原始比值，前端乘100显示%；A为0时返回null及原因。该口径可能超过100%，不要强制截为100%。

每个请求输出的分类分别返回完整、已输出、阈值过滤的面积与数量。完整交集统计始终计算；若 `includeOverlapSpots=false` 等设置明确不输出某类几何，返回 `outputRequested:false`，该类的 retained/filtered 返回null或省略，不能把“未请求输出”误算为“阈值过滤”。

### 范围覆盖

U＝用户上传/绘制的规划范围，A＝高标田，B＝永农。使用完整 U、A、B 一次逻辑上连续的空间运算，四个互斥区域为：

- 仅高标非永农：U∩(A\B)；
- 仅永农非高标：U∩(B\A)；
- 同时满足：U∩A∩B；
- 都不满足：U\(A∪B)。

另提供两个汇总分类“高标范围内（含重叠）”“永农范围内（含重叠）”，供现有六项展示。它们复用四个互斥分类，不能将六项面积一起相加。

完整四类之和应等于完整 U 的面积；完整统计和最终输出过滤统计均由后端负责。不能把前端三次已经经过面积过滤的 compare 结果当成完整分区。后端需保留最初的 U、A、B 和范围条件，或给这条计算链建立可追溯的父任务。

### 行政区划统计

对一个区划返回该区划统计；多个区划返回联合范围的总统计及每个区划的独立统计：

- 区域总面积、高标田面积、永农面积、重叠面积、仅高标面积、仅永农面积、差异面积和差异率；
- “永农中的高标田”和“高标田中的永农”使用同一个完整交集面积；
- 归属信息包含 serviceId、layerId、完整 objectIds 和区划名称。同一区划多块几何必须全部参与；
- 多区合计先 UNION 去重，再统计。若所选乡镇与其村重叠，合计不能直接相加；独立区划统计可能相互重叠，不能要求逐区之和必等于合计。

行政区裁切本身没有设置最小面积阈值时，明确返回 `thresholdApplied:false`，保持严格裁切，不为它凭空增加过滤。区域完整统计按集合面积计算；原目标图层的输出数量按实际返回要素统计。若没有生成 A_ONLY/B_ONLY 等分区图层，不要求返回这些分类的输出数量，不能拿原目标层数量冒充分类数量。

## 4. 接口建议：复用已有任务，统一查询统计

优先在现有异步任务内完成统计，复用已经修复的原始输入与完整中间几何，不另建一套重复拉取/计算逻辑。

新增统一查询接口，建议：

`POST /api/v1/spatial/statistics`

```json
{
  "deptId": "当前部门ID",
  "taskType": "OVERLAY",
  "resultId": "当前分析任务ID"
}
```

建议 taskType：`OVERLAY`、`GEOMETRY_COMPARE`、`REGION_CLIP`、`COVERAGE`。必须明确它们与现有任务ID的对应关系，不能假设不同任务表的 resultId 全局唯一。

- 统一沿用 BaseRsp 包装、POST 风格及 SPECIAL_ANALYSIS 权限，校验任务所属账号/部门与输入服务访问权限。
- 查询读取任务统计状态；如需补算旧任务，异步受理且同一任务只启动一次，不能每次轮询重复开算。
- 数据来自同一次分析的数据快照。返回输入指纹/数据版本、算法版本和阈值，确保统计与当前地图结果对应。
- 对已有 `/overlay/status`、`/overlay/detail`、`/spot/compare/status`、`/region-clip/status`，可附带相同 `statistics` 或统计就绪标记；不要再出现不同接口对同名字段使用不同口径。
- 若范围覆盖当前由多个子任务完成，需要后端提供父 resultId 或等价的明确关联，并保留原始 U/A/B 快照；请返回这部分的受理接口和关联规则，前端再调整调用，不能任取最后一个子任务当整体统计。
- 旧任务只存了过滤结果、无法恢复原始快照时，明确返回“需重新分析”；不能用过滤结果冒充完整统计。

运行中示例（以下为 BaseRsp.data）：

```json
{
  "taskType": "OVERLAY",
  "resultId": "当前分析任务ID",
  "status": "RUNNING",
  "progress": 65,
  "stage": "正在计算阈值过滤前的完整统计"
}
```

区域统计需在相同结构上增加 `total` 与 `regions[]`，每项有区划标识、名称、完整统计及适用的输出统计；单区失败可以独立返回状态、原始错误原因，不能用0填充失败项。

## 5. 一致性、失败和缓存

- 对请求输出且只实施面积阈值过滤的互斥分类：完整面积＝保留面积＋阈值过滤面积；数量亦遵循同一计数单位。未请求输出的分类不套用此等式。
- 保留数量与 GeoJSON/分页结果一致；保留面积与实际输出几何集合的面积一致。区域目标层若存在源要素重叠，面积按 UNION 去重，不能简单相加。分页、分块、导出必须完整，超限报错，不能截断再计为阈值过滤。
- 对比完整统计应满足 areaA＝onlyAArea＋overlapArea，areaB＝onlyBArea＋overlapArea。
- 全部被过滤也是成功：完整统计可非0，保留面积/数量为0，过滤面积/数量如实返回。
- 完整运算失败返回 FAILED 和原因；几何输出成功但统计失败时需单独标明统计失败，前端不能将其显示为完整成功。
- 保留现有整体任务 PENDING/RUNNING/SUCCEEDED/FAILED/CANCELLED 等约定；明确统一查询的 progress 指统计阶段还是整体任务，不伪造百分比。
- 缓存包含原始输入/属性条件、行政区选择、上传几何指纹、服务数据版本、算法及统计版本；输出缓存还必须包含 minAreaSqm、阈值单位和比较规则。
- 可以复用与阈值无关的完整几何统计，再按不同阈值生成保留/过滤统计；更改阈值不能拿到上一阈值的输出计数。
- 后端说明面积计算精度和校验容差。以未四舍五入值计算和校验，前端展示时再保留小数位。

## 6. 验收

1. 同一输入分别使用0、15、100㎡阈值：完整面积与完整差异率不变；输出面积/数量与过滤面积/数量随阈值变化。
2. 图斑面积等于阈值时按 GTE 保留；更小的图斑进入过滤统计。
3. 全部过滤、合法空输入结果、A为0、带洞、多块行政区、重叠输入和跨边界地块均有测试。
4. 六项覆盖展示保持四个互斥原子区域的守恒，汇总项不重复累计；中间阶段不因阈值丢失后续交集。
5. 多区联合合计正确去重，独立区划仍可定位到完整几何；红旗街道及城西街道多片区用例回归。
6. 状态轮询不重复计算；取消/失败不返回伪造0；数据快照和缓存版本对应同一结果图层。
7. 请交付接口地址、请求/返回DTO、字段单位与口径、阈值计量单位、父/子任务关联、错误码及真实示例；前端收到契约后接入完整统计与过滤提示。
