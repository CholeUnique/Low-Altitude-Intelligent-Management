# 非粮化无人机复核：提取已有最新图片

## 接口核对

2026-11-13 读取后端 `/v3/api-docs`，确认：

- `POST /api/v1/uav/media/match`：必填 longitude、latitude；radiusMeters 默认 20 米、最大 500 米；shootAfter 缺省查近 7 天；优先返回拍摄时间最新、已下载且未清理的照片，不返回视频。未命中为 code=0、matched=false。
- `POST /api/v1/uav/media/match/raw`：同一查询逻辑，成功返回图片二进制；未命中返回 JSON BaseRsp、code=10222。不能将错误 JSON 当作图片。
- `GET /api/v1/uav/media/file/{mediaId}`：既有素材原文件二进制接口，支持 Authorization。

两个新接口均已封装。界面使用 `/match` 获取素材编号、拍摄时间和距离，再按该编号读取原图，保证预览、来源信息和最终附件属于同一张照片；不连续调用两次匹配而让新入库照片替换已选结果。raw 封装同时处理成功二进制、JSON 业务错误和 HTTP 错误中的 JSON Blob。

## 用户操作

无人机复核对比区增加“提取最新无人机图片”，替代原来引导去一键起飞的入口。以当前图斑中心坐标查找，允许调整匹配半径和拍摄起始时间，展示图片、名称、拍摄时间与距离；确认选用后复制原图到当前复核节点附件，并只关联当前图斑。

普通航拍照片作为静态图片凭证展示，不根据单个 GPS 点虚构正射影像范围，也不强制绘制地块边界。已有手动上传、静态绘边和 GeoTIFF 配准流程保留。

原图保存为节点附件；最大边长 1280 的预览和素材来源信息随 plotResults 提交，历史已完成节点可显示。提取凭证不会自动提交复核、改变结论或推进工作流。旧附件保留，取消使用或删除当前凭证时清除对应主图引用。
