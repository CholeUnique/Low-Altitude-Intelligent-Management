## 另外发现的后端边界情况

行政区对比选择城西街道＋红旗街道、最小图斑面积设为 0 时，spot/compare 的 A_ONLY 分组出现 `seqNo=2780, diffType=A_ONLY, areaSqm=0`。前端继续拒绝零面积结果，错误提示已补具体序号、分类和面积，不删除异常记录伪装成功；默认阈值下分析正常。

请后端核查最小阈值为 0 时的碎斑过滤和面积序列化精度：输出有效正面积图斑、统计与 FeatureCollection 保持一致；退化零面积要素不应以普通面图斑返回。若只是面积四舍五入为 0，应保留足够精度或明确输出策略。
