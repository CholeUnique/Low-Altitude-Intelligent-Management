# 专题地图：图例与地图三要素

本轮以比例尺、方向、图例为整体检查对象，保留既有地图、分类、业务接口和标准色。以下是交互地图中的排版实现，不代表完成了纸质成果图的全部规范验收。

## 参考依据

- 中国测绘学会：[什么是地形图？这些符号都看得懂？](https://www.csgpc.org/index.php/detail/24500.html)，说明地图三要素为比例尺、方向和图例。
- 自然资源部《市级国土空间总体规划制图规范（试行）》，2021 年 3 月，[原文](https://www.gov.cn/zhengce/zhengceku/2021-04/07/5598163/files/bd34c2bcbb6f467d8af880abc33f4c07.pdf)，2.6 节列出图幅配置；2.6.4—2.6.6 涉及指北针、直线比例尺和由图形、线条、符号及文字组成的图例。该规范针对市级规划成果图，本页面参考其要素组织原则，不照搬纸图图廓及物理尺寸。
- ArcGIS Pro：[图例项](https://doc.esri.com/en/arcgis-pro/latest/help/layouts/work-with-legend-items.html)、[图例符号样例](https://doc.esri.com/en/arcgis-pro/latest/help/layouts/work-with-legend-patches.html)、[图例排版](https://doc.esri.com/en/arcgis-pro/latest/help/layouts/work-with-a-legend.html)。符号样例应对应地图符号，区分图层标题、分类名称及组间距。
- 地类色彩及图式继续使用项目现有 TD/T 1055—2019 附录 C.5 配置；本次不调整分类标准或颜色。

## 实现约定

1. 左侧上方为可收起的图层详情，下方为独立图例；两者共用宽度、上沿及高度变量。收起详情不移动图例，不重建地图。
2. 图例采用浅色中性底，点、线、面使用各自的符号样例；三调图式按地图的平铺尺寸裁切，避免将方形纹理压扁成矩形。边界模式保持中空，细暗色轮廓仅帮助辨认浅色线条。
3. 只列出实际显示的矢量分类及分析结果，不列背景影像。保留后端名称，不擅自合并同色地类。单符号标签与图层名相同时不重复标题。
4. 短分类名使用双列对齐，长名称跨列并换行；内部滚动并隐藏滚动条，键盘聚焦后也能滚动。图层显隐、独立铺满/边界模式和分析结果同步更新图例。
5. 右上角指北针指示当前地图上北方向。现有 Leaflet 地图不支持旋转；未来增加旋转时应将指北针同步绑定地图方位角。
6. 右下角保留随移动、缩放和尺寸变化更新的比例尺，标出 0 与带单位的终点。刻度线实际宽度与计算宽度一致，容器内边距不参与刻度长度。比例尺表达当前纬度附近的距离，不显示缺少物理屏幕尺寸依据的固定数字比例。

## 验证

使用真实部门数据检查 1728×1000、1366×768、全屏、详情收起、分类独立切换、内部滚动及工程设施点/线符号。按地图实地距离复核比例尺，不仅检查文字是否变化。
