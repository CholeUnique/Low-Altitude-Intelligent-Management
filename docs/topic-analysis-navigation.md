# 专题分析结构调整

## 导航与访问

- 智能研判侧栏新增一级“专题分析”，与“数据管理”并列。仅农业农村部门视角且具备数据管理权限时显示；自然资源视角直接访问专题地址也会被路由守卫拒绝。
- 默认二级专题：“高标准农田管理”“高标准农田工程设施管理”。工程设施下设三级“工程设施总览”“工程设施地图”。一级标题行保留 hover 新增本机专题功能。
- 新地址：`/recognition/topics?topic=HIGH_STANDARD_FARMLAND`；工程设施使用 `HIGH_STANDARD_FACILITIES`，通过 `view=overview|map` 区分页面。
- 旧 `recognition/data?dataTab=topics` 链接自动迁移。原农田专题 ID 不变，保留既有图层配置；工程设施使用独立专题 ID，配置按原有账号/部门规则隔离。

## 地图

- “分类与图例”改为“图层详情”，可以向左滑出收起。组件与地图保持挂载，不重新初始化地图，不清空已选图层或分类。
- 独立地图图例仅展示当前实际显示的矢量分类及其颜色、图式、铺满/边界状态；影像不列入。分析结果也参与图例，显隐同步。
- 分析弹窗独立挂载于地图根容器，避免详情面板收起后的 aria-hidden/inert 影响操作。
- 移除详情底部说明。场景配置移除顶部说明、项目空间筛选、分类标准；保留背景影像、完整业务数据目录及原有专题统计。
- 项目范围预读、项目空间相交查询及其隐式筛选状态全部移除。设施按用户选中的完整后端图层展示，不做项目范围裁切。

## 工程设施总览

复用当前部门已发布服务，识别含 GCMC 字段的设施图层，读取完整要素数量；按后端服务和图层原名展示。统计口径是图层要素，不推断物理设施去重数或项目归属。没有新增或修改后端接口。

## 验证

- `node scripts/geographic-topics-store.test.mjs`：旧配置迁移、新默认专题、独立配置和账号/部门隔离。
- `node scripts/topic-access.test.mjs`：农业部门可见，当前自然资源部门不可通过其他农业成员身份绕过限制。
- 原专题目录和空间分析测试继续通过。
- 浏览器验证包含旧链接跳转、hover 新增、收起时地图实例与选中项保留、独立图例、配置区域清理、工程设施两级页面、真实部门切换后的路由拒绝。
