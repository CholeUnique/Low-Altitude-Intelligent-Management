# 系统视觉与布局改造方案

版本：2026-11-08 · 待审阅方案 · 尚未实施

参考：[用户指定原型系统](https://25bajz.axuremart.com/task/list)。配套：[可复用改造提示词](visual-restyle-prompts-20261108.md)。

## 1. 建议采用的整体方向

将平台整理成一套“深蓝底色、青色强调、清晰文字层级、紧凑且稳定的布局”的视觉系统。首页、飞行作业、智能研判、任务中心和后台管理共用设计规则；地图保留遥感影像与专业制图表达；工作台长表单保留浅色阅读区，与深色流程导航组成明确的操作环境。

本次最值得调整的是：过小的业务文字、各页面不一致的留白与控件、全局 hover 对局部样式的干扰，以及多层滚动与面板高度不稳定。单纯增加发光、渐变和动画不能解决这些问题。

建议结果是：用户从首页进入专题、任务列表、工作台和后台时，能认出同一套字体、间距、按钮、状态和交互反馈；页面密度随内容类型调整。

**本轮只交付分析文档和提示词。文中的目标颜色、尺寸和布局均为待确认方案，不代表已经修改。**

## 2. 观察范围与证据边界

### 已查看的参考页面

- 单位总览：地图大屏、两侧统计面板、圆环、图层入口、底部工具栏。
- 飞行作业／机队总览：侧栏、指标卡、地图卡和设备信息分区。
- 智能研判／飞行成果：多条件筛选、统计卡、资源表格、三级导航。
- 任务列表：筛选、任务名称与编号层级、场景标签、状态、分页。
- 任务详情：指标条、流程条、基本信息、影像对比、处理记录。
- 地理场景专题：地图标题、工具栏、左侧图层浮窗。观察时处于数据加载状态，因此不评价加载完成后的分类排布。
- 后台管理：个人资料、用户管理，以及未提交的新增用户弹窗。

观察窗口约为 1280 × 721；同时读取了页面实际计算样式及已部署的样式资源。没有提交新增用户、修改资料或业务流转操作。

### 当前项目的比较依据

以本地组件和最终覆盖样式为主，结合本次对话中用户提供的页面截图。当前本地预览处于登录页，未取得所有业务页面同一窗口尺寸下的新截图，因此本文对当前项目的结论属于代码与已有截图核查；实施前还需补齐登录后的逐页截图基线。

文中的“参考实测”指页面计算样式；“参考规则”指其部署 CSS 中的明确规则；“建议”是针对我们项目制定的目标。组件库默认值不等同于页面最终值。

## 3. 从参考系统提炼的设计规则

### 3.1 统一的深色基础

参考任务列表实际使用 `dark platform-theme`。其业务主题定义：

- 页面底色 `#071630`，叠加很轻的深蓝渐变。
- 顶栏为 `rgba(11,35,71,0.85)`；面板常用 `rgba(10,36,76,0.6)`。
- 主操作蓝色 `#2F8CFF`；选中菜单与重点提示常用青色 `#22D3EE`。
- 主要文字 `#E6F1FF`，普通文字 `#C4D6EF`，次要文字 `#9FB7D9`。
- 辅助文字常用 `#6B84A8`；边框常用低透明度蓝色。

实际页面还存在标题颜色被全局规则覆盖、部分操作蓝字对深底不够清晰的情况。我们应沿用层次关系，并提高辅助文字和文字按钮的可读性。

### 3.2 字体有明确的角色

任务列表实测字体栈以 Inter 开头，中文回退到苹方／微软雅黑；输入框和表格正文为 14px，列表标题为 18px、字重 600。部分按钮计算字体为 Arial，说明参考也不是完全统一。

参考统计卡规则为：标签 13px，数字 26px、字重 700，单位 13px、字重 400，补充说明 12px。大屏另有 28px 指标。核心做法是通过字号、字重和颜色表达重要程度，数字与单位保持明显区分。

### 3.3 重复使用相同的几何尺寸

- 顶栏 CSS 高度 64px、左右内边距 24px。
- 页面常用内边距 16px；模块间距主要为 12px、16px。
- 通用模块侧栏规则宽度 200px，另有内边距和边框；不能把 CSS width 直接当作最终外宽。
- 菜单行高 42px、子菜单 38px；常见面板圆角 8px。
- 输入框实测高度约 34px、圆角 6px。
- 统计卡图标为 44px 圆形底，图标本体约 22px。

这些规律让页面有秩序，不需要每张卡片设计一套装饰。

### 3.4 反馈以颜色和边框为主

参考导航明确使用约 200ms 的背景／文字反馈，输入框阴影反馈约 200ms，按钮反馈约 100ms。选中态使用青色文字与淡青底；一般 hover 使用淡蓝底。它没有依赖整块内容位移来表达可点击。

hover 时长主要来自 CSS 规则，未对每一个控件进行逐帧测量。我们应制定自己的统一时长，避免原样复制其 `transition: all`。

### 3.5 滚动区域有容器意识，但并不完美

参考全局竖向滚动条规则为 8px，侧栏与详情局部规则为 6px；滑块圆角、低对比底色，hover 后加深。详情正文、处理记录等区域各自滚动。

参考任务列表在观察窗口中仍需页面滚动，任务详情的三列布局出现挤压与重叠。我们应学习其容器分工，同时避免固定三列宽度和一味堆叠卡片造成的溢出。

## 4. 与当前项目的差异及修改建议

### 4.1 全局交互规则影响各模块

当前 `src/styles/index.scss:28–31` 对所有按钮施加变暗滤镜和大面积内阴影，对所有 select 的 hover 强制使用深蓝背景与 `!important`。浅色任务列表或工作台中的 select 也会受其影响；同一个按钮还会叠加模块自己的 hover。

**建议：**全局只保留字体继承、基础盒模型、焦点可见性等规则；按钮、选择器、菜单分别按组件和主题定义反馈。取消统一滤镜与覆盖整面的内阴影，避免图标、危险色和文字一起变暗。

### 4.2 文字缩小过度

任务列表最终样式中，正文 11px，任务名称 12px，编号、状态和日期部分为 10px（`src/views/TaskListsView.vue:480–489`）。图层详情标题与分类控制多处为 10–12px，元信息甚至 9px。非粮工作台也有 9–11px 说明和表单标签。

**建议：**主要业务信息回到 13–14px；辅助信息通常 12px；9–10px 仅限非关键装饰性英文等少数场合。先整理列宽、行数与内边距，再调整字体，避免通过整体缩小页面解决拥挤。

### 4.3 顶栏、侧栏与菜单尺寸不统一

主顶栏现为 68px（`src/components/PrimaryHeader.vue:108`）；任务侧栏按钮 52px、文字 17px，后台侧栏又采用另一组图标、圆角和选中效果。智能研判已有统一部分一级菜单的规则，但子菜单与其他布局仍各自维护。

**建议：**保留主顶栏 68px，减少无意义尺寸变动；侧栏统一外宽与文字、图标、尾部箭头列。菜单用同一套 default／hover／active／disabled 状态。专题分析的 hover 新增沿用现有规则，仅统一视觉和对齐，不更改触发范围。

### 4.4 页面存在多套相近但不同的深色

首页有 cockpit 专用变量，后台偏蓝绿色，专题面板偏墨绿色，任务列表为浅色；相似按钮、卡片边框、背景透明度各自硬编码。

**建议：**建立平台深色和工作台浅色两组语义变量。首页、地图、后台和业务清单通过同一组语义调整，而不是逐页修改近似颜色。长表单工作台保留浅底，但其字体、控件、间距和交互与平台共用规范。

### 4.5 高度与滚动的所有权不明确

全局竖向滚动条宽度为 0，局部又出现 thin／none；布局容器、页面容器和内容面板都可能设置 overflow。专题页还存在同一选择器多次追加覆盖高度与宽度的情况。

**建议：**每个页面明确由哪个容器负责滚动。地图本身不产生页面滚动；图层详情只滚动正文；搜索框和标题固定；表格只滚动表体；工作台待办只在弹层内部滚动。先整理最终有效样式，再合并重复规则。

### 4.6 装饰多于必要的层次

首页与专题中的部分控件同时叠加渐变、发光、背景模糊、阴影及边框；后台也有独立的强阴影按钮。这会让所有区域都显得重要。

**建议：**每种容器只采用一种主要层次表达。普通面板以背景明度和细边框区分；地图浮窗才使用适度半透明与模糊；主按钮使用清晰实色；阴影只用于悬浮层。保持关键数字、当前节点和选中项最醒目。

## 5. 拟采用的统一视觉参数

以下全部是我们项目的建议值。

### 5.1 字体与信息层级

- 字体：`"PingFang SC", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`。优先使用已有系统字体，不额外加载远程字体。
- 系统品牌：22px／28px，字重 600；窄屏 18–20px。
- 页面标题：20px／28px，字重 600；专题标题可用 24px／32px。
- 卡片标题：16px／24px，字重 600。
- 主体文字、表单内容：14px／22px，字重 400。
- 紧凑表格正文与地图列表：13px／20px；长编号、时间、辅助描述为 12px／18px。
- 统计主数值：28px／34px，字重 600；首页主指标允许 32–36px。
- 单位：12–13px、普通字重、次要文字色，与数字基线对齐，间隔 4px。
- 数字启用等宽数字特性，数值更新时不使相邻单位跳动。
- 中文正文不增加字间距；标题适度增加 0–0.5px；避免大面积字距拉伸。

### 5.2 颜色与表面

- 平台页面底：`#071630`；深色实体面板：`#0B2347`；浮层：`#0D2A52`。
- 地图浮窗底：以 `#0B2347` 为基准，建议 92%–96% 不透明度，避免遥感影像干扰文字；普通业务页面面板使用实体背景。
- 深色主文字 `#E6F1FF`，正文 `#C4D6EF`，次要文字 `#9FB7D9`；更弱的文字仅用于非关键说明。
- 主操作 `#2F8CFF`，选中／信息强调 `#22D3EE`；深底文字链接使用更浅的蓝色，避免暗蓝字。
- 成功 `#20C997`，警告 `#FFB020`，错误与必填 `#F56C6C`，中性状态使用灰蓝。状态同时显示文字，不能只靠颜色。
- 浅色阅读区：页面底 `#F3F6FA`、面板 `#FFFFFF`、主文字 `#21354C`、正文 `#40566C`、次要文字 `#65788B`、边框 `#DCE5EE`。
- GIS 地类标准色、空间分析分类色、识别结果颜色保持已有语义，不随界面品牌色批量替换。

### 5.3 间距、形状与图标

- 间距统一采用 4／8／12／16／24／32px。
- 标准页面外边距 20px，窄屏 16px；模块间距 16px，密集地图面板内间距 12px。
- 卡片圆角 8px，输入和按钮 6px，弹窗 10px；普通状态标签 4px。
- 分隔线 1px，深色页面低对比；普通卡片不加明显外发光。
- 操作图标统一线性风格，常用 16–18px；侧栏图标 20px；不再混用字符图标、粗细不同的 SVG 和强装饰底座。
- 普通控件高度 36px，紧凑地图工具 32px；文字按钮不小于 28px 点击高度；图标按钮建议 32–36px 点击区域。

## 6. 整个系统的布局规范

### 6.1 顶栏与导航

主顶栏保持 68px，品牌区、主导航、账号区采用稳定的网格分区。1366px 下优先缩减导航间距和品牌字号，不挤压账号、部门名称。时间等辅助信息按已有响应式规则处理。

侧栏建议外宽 216–220px，一级菜单 44px、二级 38px；图标列 24px，尾部箭头／新增操作列 24px。文字在固定列内省略，hover 不改变宽度，不隐藏普通一级菜单箭头。

**保留现有路由与导航层级。**不复制参考站的旧“地理场景专题”入口，不将我们的“专题分析”移回数据管理。工作台和后台继续使用自身标题与返回入口，不恢复多余的外部 header；任务列表不恢复用户已要求删除的页面 header。

### 6.2 筛选栏与表格

筛选标签、输入、选择器、搜索和重置按钮对齐；控件间距 12px。较窄窗口允许筛选区域自然换为两行，不通过压缩到 10px 字体保持一行。

任务名称与编号采用主次两行；所属场景与状态允许限行换行；当前处理人继续保留。任务列表建议行高 68px、表头 40px，所有数据行等高；主要正文 13px，编号和日期 12px。按当前实际列数重新分配宽度，优先减少单元格横向留白，保持名称可读且不占据过多宽度。

任务状态列固定宽度建议 88–104px，使用最多三行的文本标签；颜色保持语义。过长文字保留完整提示。表格整体尽量不出现横向滚动，不得以隐藏溢出的方式丢失“操作”“当前处理人”等必要列。若 1366px 下无法同时满足，需在样式评审中明确列宽方案，不能直接隐藏业务列。

表头与分页保持稳定位置，表体使用剩余空间滚动。普通行只用轻分隔线；hover 高亮整行，选中态更明显；固定列背景与普通列状态同步，避免接缝。

### 6.3 表单、弹窗与浮层

表单标签 13–14px；输入内容 14px；标签到输入 6px，字段组间距 16px。必填星号统一红色、16px，位置和基线一致，不跟随不同模块各自变色。

普通弹窗宽度建议 560–640px，复杂配置弹窗 760–880px，上限为视口宽减 48px。标题 18px，正文与底部各有清晰间距；最高不超过视口高减 64px。标题和按钮栏固定，正文内部滚动；默认操作区右对齐，主次按钮间距 8px。

Tooltip 建议出现延时 150ms、消失延时 80–100ms，内容 12px／18px，使用实底深蓝浮层与细边框；避免浏览器原生 title 承担需要快速反馈的节点信息。已存在的自定义提示只统一样式和延时。

### 6.4 滚动条

采用“限定容器＋统一滑块”的规范。普通表格、后台长列表、弹窗正文建议 6px 细滚动条，透明轨道，深色滑块 `rgba(159,183,217,.35)`，hover 为 `.55`；浅色容器使用灰蓝滑块。预留稳定滚动空间，出现滚动条时不改变内容宽度。

**保留此前明确的例外：**地图图例不加滚动条、背景透明并贴底；工作台右上待办内部可滚动但隐藏滚动条；地图本身和整屏大屏不产生浏览器页面滚动。普通表格采用可见细条是本方案提出的变化，实施时按本次文档审阅结果执行。

不能全局设置横向 overflow hidden 来掩盖表格、工具栏或弹窗布局错误。

### 6.5 hover、焦点与动画

- 普通按钮、菜单、表格行：背景／颜色／边框 160ms，`ease-out`。
- 折叠三角：旋转 180ms；图层正文使用透明度与受控展开，不使列表整体跳到底部。
- 面板收起／展开：统一 220ms，同一操作触发的面板同时开始结束；不对 width／height／all 做不受控的全局过渡。
- 弹窗：透明度与不超过 6px 的轻位移，180ms；不弹跳、不大幅缩放。
- 禁用态不触发 hover 高亮；active、hover、focus-visible 分别有明确样式。
- 键盘焦点使用 2px 清晰描边，不能仅去除 outline。
- 尊重系统减少动态效果设置；大屏装饰动画保持低频，不影响地图交互。

## 7. 各页面的具体改造内容

### 7.1 首页／单位总览

统一两侧卡片标题、边框、内边距和统计文字层级。使用共享面板背景与标题条，减弱多重渐变、背景花纹和发光。保留已有数值动画，但固定数值占位与卡片尺寸；图标轻微浮动只用于少数装饰，不让业务按钮移动。

右侧“智能识别成果—专题分析—任务相关卡片”的现有顺序及内容保持。高标田面积、永农面积、差异率的数字突出，单位和标签弱化；不改变数据来源、计算口径或账号缓存规则。识别面积继续用亩。

短屏时先缩减卡片间距和装饰高度，保留标题与核心指标；明细在卡片正文内滚动。首页已移除的统计和要素详情浮窗不恢复。

### 7.2 飞行作业

机队总览采用统一指标卡和地图卡；工单、计划、航线列表应用同一筛选和表格规范。设备在线、离线、告警色与首页一致。

实时作业保留视频、地图、设备信息的比例关系与已有 iframe 适配逻辑。样式修改仅处理外部容器，不改第三方页面内容、不裁切必要控制区、不改变播放或定位逻辑。

### 7.3 智能研判与数据结果

一级菜单使用同一图标、行高、箭头列和交互；二三级菜单用缩进与轻选中底色表达层级，减少重复重边框。资源筛选、指标卡和结果表之间使用统一 16px 间距。

采集成果、识别结果、算法卡片共用标题、状态标签、空态和按钮体系。保留所有现有业务入口、权限与操作数量，不照搬原型里的旧入口和示例数据。

### 7.4 专题分析地图

地图占满可用区域，标题区和工具栏保持同一顶部基准；工具栏从测量、标注、绘制、空间分析到其他工具的现有顺序不变。图标、按钮高度、分隔线和下拉菜单统一。

左侧图层详情与右侧统计面板使用同一顶部变量，建议宽度分别约 340px 与 300px；具体数值随视口适配。图层详情标题和搜索固定，列表占剩余空间滚动。面板总高度由可用视口决定，展开分类、显示结果和切换 checkbox 时不跳变。

已有图层、上传图层和分析结果采用同一张图层卡的标题、折叠三角、选择控件和模式控件；结果分组及子项关系保持。统一“全选／打开”的现有单 checkbox 表达，不重新加入“反选”或重复“显示”。

地图右侧分析统计采用一致的指标栅格；数字建议 24–28px、青色或浅亮色，单位 12px；统计项多时在右侧面板内部滚动。保留现有按可见分析结果切换统计的判断逻辑。

图例继续独立贴底、透明、自适应内容高度；指北针与比例尺仍在右下，透明底。图例符号与地图真实样式同步，背景影像不进入分类图例。不因模仿参考站而恢复全局铺满切换、旧场景下拉框或图例整体折叠按钮。

### 7.5 高标准农田工程设施总览与地图

与高标田管理共用地图工具、图层卡、统计卡和字段详情样式；工程设施总览的指标字体、单位、状态一致。保留设施类型的业务符号，图例透明、贴底、不加滚动条。

### 7.6 任务中心与任务详情

任务总览统计卡与首页指标采用同一标签／数字／单位结构；图表统一坐标文字、图例和提示框。任务列表按第 6.2 节处理。

任务详情采用明确的“摘要—流程—正文”层次。宽屏允许多栏，窄屏不固定复制参考站的 `320px＋中间＋320px` 三列；应依据可用空间调整排列，确保影像与记录不重叠。内容字段、处理人、流程节点、动作和权限不变。

### 7.7 非粮、工程设施及其他工作台

保留深色流程导航与浅色表单区，统一模块标题、边框、文字、必填符号、输入与操作栏。流程节点状态采用统一连接线与圆点，当前节点强调、已完成弱化；“我”为橙色、其他人为蓝色的处理人角标保持，首节点继续不展示操作人与时间。

表单阅读顺序和既有地图、材料、处理记录分区不变；密集区从 10–11px 调整到可读尺寸，允许内部滚动。待办弹层限制在视口内，不能撑高整个页面。所有自动带入、结案选项禁用规则、真实节点映射与业务提交逻辑都不属于本轮修改范围。

### 7.8 后台管理与登录

后台使用平台深色基础，保留独立的上下文标题和返回入口。个人资料、用户、部门、场景、权限、元数据、地图服务、日志页面统一内容外边距、筛选、表格、编辑弹窗和反馈样式。减少独立按钮渐变和大阴影。

登录页只统一字体、品牌色、输入与按钮状态；不修改登录流程、权限、账号预填、凭证存储或部门判断。

## 10. 验收标准

- 检查 1920×1080、1600×900、1366×768，另检查浏览器缩放 125% 后的可用空间。
- 主体文字清晰，字号遵守角色；不能靠整页 transform 缩小或 9–10px 正文容纳内容。
- 顶栏、侧栏箭头、按钮图标、表头与数据列对齐；hover 前后尺寸不变。
- 任务数据行等高、当前处理人和操作列完整；长状态换行但不撑高单行。
- 地图左右面板顶部一致；切换分类、展开结果、关闭详情不引起整个面板跳高或移位。
- 图例、指北针、比例尺保留透明背景和既定位置；地图仍可正常缩放、拖动和点击。
- 图层模式、勾选、上传、分析、导出等现有操作在换肤后保持原有结果。
- 所有可滚动区域都可用滚轮／触控板访问末尾；禁止整页双滚动和被裁切的分页／提交按钮。
- hover、选中、焦点、禁用、加载与错误状态清晰；同类组件动画一致。
- 检查深浅主题文字与背景对比，普通文字以 4.5:1 为目标；减少动态效果模式下无持续装饰动画。
- 业务接口、参数、权限、路由、工作流和统计口径不变；请求数量不能因视觉动效增加。
