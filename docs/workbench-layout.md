# 工作台统一布局规范

适用于所有现有和新增任务工作台，包括通用、非粮化、工程设施、违法用地预警和整改场景。

## 必须复用的公共入口

- 顶部统一使用 `src/workspace-components/shared/WorkbenchHeader.vue`，禁止再复制场景专属 header、节点步骤或待办通知布局。
- header 左侧为返回按钮、工作台名称，所有工作台均不显示副标题（包括任务名称）；任务名称、编号放在正文任务信息区。中间为真实工作流步骤；右侧为待办通知。深色背景 `#08283c`，桌面高72px，横向内边距14px，间距12px，标题15px、步骤12px。窄屏由共享组件把步骤放到第二行，节点可横向查看。
- 步骤统一由 `WorkflowSteps.vue` 渲染；当前处理节点高亮，选中回看节点单独标识，完成节点打勾。复用 `WorkflowActorBadge.vue` 展示实际操作人和提交时间；不得把创建时间冒充处理时间，未提交显示办理中。未到达节点不可操作，已完成节点只读。通知只有其他待我处理任务时显示红点，不显示数量。
- 场景组件只提供标题、步骤、办理人、时间和业务事件，不自行重写共享组件样式。任务受理和各业务节点的内容可以按场景安排，但节点切换不能丢失公共工具。

## 正文布局与办理表单

- 以“耕地用途监管工作台”为规范：顶部四项任务摘要（任务编号、场景、图斑数量、当前办理人），下方左侧图斑缩略图与任务处理记录，右侧前后期影像对比与当前节点表单。任务编号和名称须在正文可见，不放回 header 副标题。
- 影像优先使用任务创建时保存的前后期次，并叠加任务真实几何；复用 `NonGrainImageryComparison.vue` 的并排、卷帘、同步缩放和全屏。无该期影像明确说明，不能以无关影像代替。历史节点同样保留图斑和影像上下文。
- 表单上方展示当前节点、图斑、实际办理人、部门或提交时间。必填标签复用 `WorkbenchRequiredMark.vue`，与字段名同一行；必填校验以真实后端节点要求为准。只读节点不提供可提交表单。
- 左侧记录显示实际操作人和操作时间，长记录、长表单各自滚动，任务摘要与公共 header 保留。窄屏允许正文纵向滚动，禁止截断内容。

## 右侧悬浮工具球

- `WorkspaceView.vue` 在所有工作台外侧只挂载一次 `WorkspaceToolBall.vue`。新增场景自动继承，不再在节点页、场景页另放悬浮位置窗口或重复工具球。
- 默认收纳；点击工具球展开工具条，再点击“任务位置与导航”图标显示位置地图，重复点击收起。工具球52px，固定右边距12px，只能沿右侧上下拖动；松手和容器缩放时限制在可见边界内，禁止左右移动。拖动不得触发点击。支持键盘上下键、Home、End。
- 弹窗向左展开，窄屏自动上下避让；不参与主体排版、不挤压表单。工具层级520，高于 header100；导航二维码使用现有弹窗层级。拖动、展开有短过渡，尊重减少动画设置。
- 位置地图使用普通电子底图，展示任务真实点、线、面及坐标。无数据明确显示缺失，禁止填演示中心点。优先读取任务范围，设施任务可回退到详情中的真实设施几何。按需读取并在同一任务内复用结果。
- 工作台坐标读数为 **CGCS2000 经纬度 / EPSG:4490**，调用 `location-coordinate.ts` 转换。后端 GeoJSON 的 WGS84 合同保持原样供渲染和导航使用；不能仅改标签，也不能直接把投影米坐标送进 Leaflet。现有转换不包含地区实测的高精度基准改正参数，不承诺测绘级基准转换精度。
- “去导航”直接复用飞行成果已有的 `NavigationQrDialog.vue`：高德、腾讯、百度三地图扫码，以及百度网页/App码切换。导航传原始经纬度，让公共组件执行既有 GCJ-02、BD-09 转换，禁止把显示用投影坐标、重复偏移后的坐标或猜测位置用于导航。
- 当前只有位置地图一个工具。后续工具放入同一工具条，不新增独立悬浮容器。

## 修改后的核对

检查所有工作台及历史节点：header 一致、实际办理人/时间正确、只有一个工具球、上下拖动边界正确、重复点击收起、CGCS2000 坐标、点/线/面完整、缺失位置状态、三种地图二维码与百度双模式。普通页面主体与业务地图不受工具打开或收起影响。
