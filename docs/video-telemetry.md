# 视频协同展示

入口：智能研判 → AI 线索发现 → 查看成果 → 播放视频 →「协同展示」。小窗显示录制时的无人机位置，不是当前设备实时遥测，也不是镜头拍摄中心的位置。

## SRT 来源

- 打开小窗时用**当前视频素材 ID** 调用 `GET /api/v1/uav/media/srt/{mediaId}`，通过既有 API 客户端携带登录权限读取二进制字幕，不再依赖素材列表中存在同名 `.srt`。代码路径为 `/v1/...`，由客户端统一添加 `/api`，避免重复前缀。
- 任务中不同名的 SRT 可以通过小窗下拉框手动选择。
- 没有线上 SRT 时点击「选择 SRT」，本地文件仅在浏览器中读取，不上传。
- 手动选择列表中的 SRT 附件时，复用 `/v1/uav/media/file/{id}` 素材地址；没有本地素材地址时匿名请求 `originalUrl`，远端需要允许跨域读取。不会把系统登录令牌发给第三方，也不会把视频原文件 URL 当成字幕读取。
- 未就绪/404 时明确提示，并提供重试和手动选择入口。**不自动调用** `POST /api/v1/uav/media/srt/generate`：该操作会触发后台生成，截图未给出请求参数和响应协议，需确认接口详情后再接入显式生成操作。

## 同步与数据约束

- 使用视频 `currentTime` 对照 SRT 相对时间轴，小窗内部以最高约 30 fps 更新，避免让整张飞行成果表随播放高频重渲染。暂停不推进，拖动、倍速和重播仍用媒体时钟。不同视频切换、关闭弹窗或切换部门会销毁旧请求、动画帧和地图。
- 相邻、连续的有效采样采用线性插值改善移动平滑度；插值位置属于估算，不是新增实测点。不跨 GPS 缺口、超过 2 秒的采样间隔或推算速度超过 100 m/s 的异常跳点插值。尾部不外推。
- 标记高频更新，跟随镜头仅在标记离开地图中央区域时平滑平移，不每帧触发瓦片重排。拖动进度跳转立即更新位置，不做长时间追赶动画；手动拖动地图暂停跟随。
- 支持 `latitude/longitude`（也接受 `lat/lon/lng`）及相对/绝对高度字段，时间分隔符可为逗号或小数点。旧版 `GPS(a,b,c)` 仅在坐标范围能唯一确定顺序时使用；歧义坐标不猜测。
- 原始坐标保持 WGS84，使用现有天地图 Web Mercator 底图；没有底图配置或瓦片加载失败时仍显示轨迹和坐标。
- 时间缺口、越界坐标、无效 GPS `(0,0)`、首尾范围外均不沿用上一次位置。轨迹断点不跨越缺失区间连线。为了小窗绘制性能对路线抽稀，当前位置查询仍使用完整记录。
- 文件最大 20 MB，最多 20 万条时间记录，支持 UTF-8 与带 BOM 的 UTF-16。普通对白字幕不包含经纬度时无法定位。
- 视频如果经过裁剪、拼接而 SRT 没有同步处理，会有时间偏差；手动选择时需确认来自同一个原始视频。本期不自动猜测时间偏移。
- 使用播放器上方「全屏查看」进入页面内全屏可保留协同小窗；浏览器原生视频全屏不包含视频以外的 HTML 控件。
- 普通/全屏模式单击视频画面切换播放/暂停，不再因单击画面进入全屏。底部原生播放、进度、音量等控制条保留默认交互；播放失败会显示提示。
- 每次打开小窗默认停靠在**实际视频画面**的右上角，按 `object-fit: contain` 计算显示范围，不把上下/左右黑边当成画面；进入或退出页面内全屏后重新停靠。普通模式默认 340×300，全屏默认 420×350；若画面更小则自动收缩。
- 按住小窗标题栏可用鼠标/触摸拖动，位置限制在实际画面内。也可聚焦标题栏后用方向键移动。地图内拖动和标题栏拖动分开处理。
- 左右下角均可拖动调整宽高；左下角适合向左放大靠右的小窗。正常最小 300×250，不设固定像素最大尺寸，只受实际视频画面边界限制；小画面优先防止越界。手柄可聚焦后用方向键缩放。
- 手动选择的尺寸在当前弹窗内保留，普通画面不足时暂时缩小，回到全屏可恢复；关闭重开恢复默认。地图随窗口尺寸变化重新布局，不重载视频/SRT，不影响播放时间和暂停地址查询策略。
- 标题栏仅保留关闭按钮，不显示缩小、放大和全屏按钮；视频全屏仍从原播放器入口操作。
- 关闭按钮悬停提示「关闭协同展示」，不继承标题栏的拖动提示。
- 去除地图右侧缩放按钮，仍可滚轮/触摸缩放；小窗不再显示底部文件说明和地图来源文字。

## 数据行与具体位置

- 时间、经纬度、相对高度使用三列单行布局，小窗宽度调整为 420px（窄容器内自适应），数字字号随小窗宽度缩放。缺失高度仍保留占位，不破坏三列结构。
- 经度使用 E/W，纬度使用 N/S，均保留六位小数。例如 `119.839961°E, 32.477212°N`。不能把经度标成 N 或纬度标成 E。
- 数据行下一行展示「当前位置」，按钮位于位置行下方。文件名仅在更换 SRT 入口悬停提示，不再占一整行。
- 地址使用现有 `VITE_TIANDITU_TOKEN` 调用天地图 `https://api.tianditu.gov.cn/geocoder` 逆地理编码，传入当前回放坐标 `lon/lat`、`ver:1`、`type=geocode`，读取 `result.formatted_address`。只发送地图密钥，不发送业务 Bearer 令牌或 Cookie。
- 密钥需具备逆地理编码权限且允许当前页面来源；无密钥、权限不足、超时、无地址都显示真实错误状态，不猜测村镇名。地址代表地图服务解析的附近位置，不代表设备当前实时位置，也不保证精确到房屋。
- **仅当前视频第一次点击开始播放时查询一次地址**；恢复播放、播放中打开面板以及重复 `playing`、缓冲和普通播放帧均不新增地址查询。父播放器记录是否已开始过播放，关闭/重开协同面板不会重置此标记。首次播放事件发生时 SRT 尚未加载好则就绪后补查该事件的媒体时刻，无有效 GPS 时不因后续移动不断重试。
- 暂停时仍查询当前位置，包括暂停状态打开小窗、字幕就绪和暂停拖动进度结束。恢复播放会取消旧暂停请求，但不新增查询；拖动会取消等待和在途查询，连续播放中的拖动结束不查询，暂停拖动结束则查询最终帧。
- 首次播放取得的地址显示为「首次播放位置」，暂停取得的地址在继续播放时显示为「上次暂停位置」，避免误认为地址持续实时更新。地图标记、经纬度、高度和时间仍随视频更新。
- 地址查询仍使用约 20m 网格缓存，频繁播放/暂停/拖动时最多每 3 秒一次查询，同网格成功缓存 5 分钟、失败退避 30 秒，最多 128 个缓存条目。查询时定位缺失、视频切换和关闭不沿用旧地址；旧坐标返回结果不能覆盖新坐标。地址查询独立于轨迹动画，不阻塞播放。

## SRT 完整信息页

- 采集数据页复用同一协同面板和 SRT 信息弹窗。视频卡片文件名行右侧提供「SRT 信息」按钮（无箭头），不触发视频预览，图片卡片不显示此按钮。字幕列表限定为该素材所属任务的视频；跨任务切换预览时保留各自任务 ID，不按同名文件猜测匹配。
- 采集数据的视频预览左上角提供「协同展示」开关；小窗拖拽、缩放、回放定位和首次播放/暂停查询规则与飞行成果页一致。切换素材、关闭预览、重试或播放失败会关闭旧协同面板。单击视频画面切换播放/暂停，原生控制条保留默认行为。

- 飞行成果页仅通过预览侧栏每个视频的「SRT 信息」按钮打开，成果表操作栏不显示此按钮。侧栏按钮不带箭头，位于时间行右侧，不另起一行，也不占用完整文件名一行。进入时暂停正在播放的视频，可在信息页切换同计划的视频。
- 复用 GET `/api/v1/uav/media/srt/{视频素材ID}`，不调用生成接口。页面包含总览统计、高度趋势、源文件信息、全部字段、可搜索和分页的字幕记录、逐条字段详情与原始全文。未知字段和没有 GPS 的记录仍保留，未识别的格式可通过原文查看。
- 支持展开窗口、下载原始 SRT、Esc 关闭；异步切换来源和关闭时取消旧请求，防止串数据。SRT 内容只以文本显示，不执行 HTML。
- 下拉框悬停/聚焦采用深色底白字，菜单项仍为白底深字。主要数据采用 14px 字号，次要说明至少 12px；去除总览卡片英文眉题、原始采样标签和数据源右侧的只读说明，不保留占位空间。
- 视频左侧协同展示和右侧全屏按钮调整至距对应上角 6px。

## 验证

新增的 SRT 信息测试覆盖完整字段提取、缺失 GPS/异常时间保留、原文安全显示、搜索筛选分页、视频切换竞态、下载、失败重试及关闭清理。
采集数据集成测试挂载真实页面，覆盖卡片按钮独立点击、长 ID/同名跨任务视频区分、共享组件参数、首播状态、素材切换/重试/失败清理、图片预览隔离及退出页面清理。

`npm run test:video-telemetry` 覆盖解析、边界/缺口/异常跳点插值保护、30fps 局部播放时钟、标题拖动与边界校正、平滑相机与地图拖动隔离、直接字幕接口与长素材 ID、未就绪重试、真实 Vue 组件挂载后标记同步及数据/地址/按钮排列、经纬度方位符、地址查询限频/缓存/竞态/退避/取消、文件读取权限隔离。上线仍需使用业务实际视频与配套 SRT 验证格式、时间对齐及地图密钥的地址服务权限。
