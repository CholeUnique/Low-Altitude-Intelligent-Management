# 系统视觉改造提示词

版本：2026-11-08 · 系统主色保留 `#072941` · 供实施及后续维护复用。

配套依据：[系统视觉与布局改造方案](visual-design-review-20261108.md)。使用时先给出“总提示词”，再添加本批对应的模块提示词。只执行用户已经确认的文档范围。

## 1. 总提示词

```text
你是负责政务 GIS 与业务协同平台的前端视觉工程师。请依据已确认的《系统视觉与布局改造方案》，参考 https://25bajz.axuremart.com/task/list 的整体视觉规律，改造当前 Vue 项目的样式和布局。

目标：形成统一的深蓝背景、蓝色主操作、青色强调、清晰字号层级、稳定布局和克制动效。首页、飞行作业、智能研判、任务中心、专题分析、后台管理共用规范；长表单工作台保留浅色阅读区；地图保持遥感影像与专业制图表达。

只修改已授权的样式、表现性布局和必要的无业务影响标记。禁止修改接口、请求参数、请求频率、权限、部门判断、路由、业务字段、工作流映射、统计口径、图层数据与 GIS 运算。不得把参考原型的示例数据、旧菜单、旧业务流程带入项目。不要新增无关功能。

先检查项目约束和未提交修改，保留用户现有工作。查明最终生效样式，建立共享颜色、字号、间距、圆角和动效变量；合并重复覆盖，限定组件样式作用域。禁止使用全局 button/select hover 强制改色、整页滤镜、transition:all 或整页缩放解决局部问题。

字体优先使用系统中文字体，主体14px、紧凑正文13px、辅助信息12px、卡片标题16px、页面标题20px、核心指标28–36px。数字和单位分开设置颜色、字号、字重，数字采用等宽特性。不得用9–10px正文挤压业务内容。

深色基础：品牌与页面主色#072941、业务面板使用同色系轻透色层，地图浮窗使用半透明深蓝渐变与适度模糊，弹窗保留较高不透明度；文字#E6F1FF/#C4D6E6/#9FB7C9；主操作使用更适合白字对比度的蓝色#2674D4，重点#22D3EE。浅色阅读区使用#F3F6FA页面、白色面板和#21354C主文字。地图地类标准色、分析分类色及业务状态语义保持不变。

间距使用4/8/12/16/24/32px，普通卡片圆角14px，控件9px，弹窗18px，普通控件高度36px。hover主要调整背景、边框和文字，约180ms；折叠180ms、面板同步收起220ms。禁用态不响应hover，focus-visible有清晰描边，尊重减少动态效果设置。不要让卡片、菜单在hover时改变位置或尺寸。

限定滚动容器：地图与大屏不产生整页滚动，图层详情滚动正文，表格滚动表体，弹窗滚动正文，工作台待办内部滚动且隐藏滚动条。地图图例透明贴底、按内容撑高且不加滚动条。普通列表细滚动条是否启用，以用户已确认的文档为准。

保留已确认结构：工作台和后台不恢复多余外部header，任务列表不恢复已删除header；专题分析保持现有农业农村局权限与菜单层级、hover新增；图层保持单一“全选/打开”checkbox、独立模式、结果分组；GIS三要素透明；首页不恢复已删除浮窗；工作台“我”橙色、其他人蓝色。

按小批次实施，先给出本批涉及页面和样式范围，再完成修改和必要验证。检查1920×1080、1600×900、1366×768以及125%缩放，提供修改前后可对照效果。报告改动、验证结果和未解决的布局限制，不能把未实际观察的状态写成已验证。
```

## 2. 第一批：共享规范、顶栏与侧栏

```text
本批只处理共享视觉变量、主顶栏、各模块侧栏和基础控件。主顶栏保留68px，菜单统一文字、图标、尾部箭头/新增操作三列。侧栏外宽约216–220px，一级菜单50px、二级38px；文字与图标对齐，hover不改变宽度。

为default、hover、active、disabled、focus-visible制定统一样式。普通一级菜单hover不丢箭头；专题分析仅在现有授权的父级hover范围显示新增图标，不能因hover子项或点击后残留。只调整表现，保留权限、导航和事件。

移除全局强制select深色hover、按钮滤镜和覆盖整面的内阴影，改为组件主题规则。统一按钮、输入、单选/复选框、状态标签、Tooltip与弹窗。不得覆盖地图地物样式。

验收：深色导航、浅色工作台输入、危险按钮、禁用按钮均无样式污染；各侧栏一级菜单动画一致；窄屏品牌、部门与账号不互相挤压。
```

## 3. 任务列表、总览和详情

```text
按共享规范改造任务页面，只优化呈现。任务列表保留全部现有列、当前处理人筛选和操作，不恢复已删除header。重新分配名称、场景、状态与处理人列，名称及编号形成主次两行，名称不过度占宽，状态限行换行。

建议表头40px、数据行68px且等高，正文13px、辅助12px；不能用10px正文或overflow:hidden掩盖列丢失。筛选控件36px，空间不足时自然换行。表头与分页稳定，表体内部滚动，固定列与普通列hover背景一致。

任务总览统一指标卡和图表文字。任务详情形成摘要、流程、正文层级，多栏布局在窄屏重新分配空间，避免影像、记录与表格重叠；不复制参考原型固定三列造成的挤压。保留所有真实流程节点和业务操作。

验收长任务名、长状态、空处理人、多流程节点与满页记录，确保没有必要列被裁切、行高变化或按钮不可见。
```

## 4. 专题分析、图层详情与工程设施地图

```text
本批统一专题地图的浮层样式，保持现有地图、图层、分析与配置逻辑。标题和工具栏对齐，左右图层/统计面板共用顶部基准；工具栏现有测量、标注、绘制、空间分析等顺序不变。

图层详情采用稳定外部高度，标题和搜索固定、列表内部滚动。已有、上传和分析图层使用一致标题、折叠三角、单一“全选/打开”checkbox、铺满/边界控件与间距。分析结果仍为一个父标题下的可独立控制子图层；不改勾选和统计联动。

主要图层文字13px，辅助12px；左右面板建议340/300px并响应视口。统计数字24–28px，单位12px，面积保持亩，不重复换算。右侧多组统计在容器内部滚动。

图例与指北针、比例尺保持透明背景，图例贴底且按内容自然撑高，无滚动条；保留现有长图例布局适配。底图影像不出现在分类图例。禁止调整地类标准颜色或改变分析几何/配色语义。

验收展开折叠、多分类、多个分析结果、上传图层、右侧要素详情以及面板收起后的碰撞情况。hover地物、高亮、提示、地图缩放和导出均保持原有行为。
```

## 5. 非粮与工程设施工作台

```text
统一工作台的字体、表单、流程条、分隔、必填符号和提示层。保留深色流程导航与浅色阅读区，不新增外部header，不改变节点、字段、读写权限和提交逻辑。

正文14px，密集信息13px、辅助12px；必填星号红色16px且基线统一。表单组间距16px，控件36px，操作栏位置稳定。内容允许按正确容器滚动，禁止为塞入整屏而缩小全部字体或裁切材料/表单。

首节点继续不展示处理人与时间；其余处理人角标“我”橙色、别人蓝色。Tooltip出现约150ms，深蓝半透明浮层，清晰显示既有姓名与时间。只调整现有提示的样式和延时。

右上待办弹层只保留当前既定任务过滤逻辑，限制在视口内，内部滚动且隐藏滚动条，不能撑高整页。保留自动带入、种植用途、结案禁用选项与工程设施真实流程映射。

验收不同节点、只读态、长名称、大量待办和材料列表；确认样式修改没有新增接口调用或改变表单值。
```

## 6. 首页与飞行作业、智能研判资源页

```text
首页保留现有卡片顺序、数据来源、统计口径和交互，统一标题16–18px、指标28–36px、标签13px、单位12px。数字和单位基线对齐，数值变化不引起卡片跳动。恢复首页半透明渐变与柔和高光，保留底图透出；卡片圆角14px，左右对称外边距、纵向16px间距。内部避免重复实底、重边框和多层模糊，文字保持清晰。

保留已有数值动效，少量装饰图标低频浮动；不增加随机数、不改变显示数值、不引入刷新接口的计时器。短屏优先压缩装饰与间距，核心指标完整显示，明细在卡片内滚动。

飞行作业、资源成果、识别结果和算法卡片沿用同一指标卡、筛选、表格、状态与按钮规范。视频及iframe只调整外部布局，保留原比例适配和控制区，不改播放器逻辑。首页已移除的浮窗不恢复。

验收大屏卡片无遮挡、机队指标可读、视频完整、长资源名可辨识，减少动态效果模式可关闭装饰动画。
```

## 7. 后台、登录和全系统收尾

```text
后台沿用平台深蓝基础，保留独立上下文标题和返回入口。个人资料、用户、部门、场景、权限、元数据、地图服务和日志统一外边距、标题、表格、筛选、编辑弹窗、空态与消息反馈。

弹窗建议普通560–640px、复杂760–880px，宽高均受视口约束，标题和底部固定、正文内部滚动。表单正文14px，辅助12px，主次按钮清楚，危险操作色保持明确。登录只统一品牌、字体、控件及反馈，不调整认证或凭证存储。

最后检查所有同类组件是否还有独立硬编码和重复覆盖；检查不同主题hover污染、双滚动、页脚被裁切、Tooltip被遮挡、键盘焦点和禁用状态。按三个目标尺寸和125%缩放提供核对记录，说明实际检查页面与无法检查的范围。
```

- 对必要的构建、类型检查及交互回归报告真实结果；不为颜色与间距写镜像实现的无效测试。
